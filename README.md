# Check & Calm

Мобильное приложение для проверки выключенных электроприборов, света и газа.

## Возможности
- Добавление квартир, домов, дач
- Комнаты с розетками и выключателями
- Отметка времени проверки
- Переименование всех элементов
- Русский / English язык
